# Back Office

Πλατφόρμα multi-company για back office στην Ελλάδα:

- **Επισκόπηση** με KPIs σε όλες τις επιχειρήσεις
- **Γρήγορη καταχώρηση** εσόδων/εξόδων (για συνεργάτη)
- **Οικονομικά** κινήσεων
- **Υποχρεώσεις**: μισθοδοσία, ΕΦΚΑ, εφορία/ΑΑΔΕ, ΦΠΑ

## Τοπική εκτέλεση

```bash
npm install
npm run dev
```

Άνοιξε [http://127.0.0.1:3000](http://127.0.0.1:3000). Χωρίς `DATABASE_URL` χρησιμοποιεί in-memory PGlite με δεδομένα δείγματος (Πράξη & Πρόοδος, MK Creation, eSM Web Devs).

## Σημείωση

Το MVP παρακολουθεί ποσά και προθεσμίες· δεν αντικαθιστά λογιστικό λογισμικό ή υπολογισμό εισφορών ΕΦΚΑ.
