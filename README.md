# cv

Προσωπικό CV και το εργαλείο **Ισοζύγιο** για λογαριασμούς / χρέη.

## Ισοζύγιο

Web app με τοπική αποθήκευση: [oikonomika/](./oikonomika/)

- Σύνολα: έχω / χρωστάω / καθαρή θέση
- Προσθήκη, επεξεργασία, διαγραφή εγγραφών
- Εξαγωγή / εισαγωγή JSON

```bash
python3 -m http.server 8000 --bind 127.0.0.1
# http://127.0.0.1:8000/oikonomika/
```
