# Ισοζύγιο

Web app για προσωπικούς λογαριασμούς και χρέη: **πόσα έχεις**, **πόσα χρωστάς**, **καθαρή θέση**.

## Χρήση

Άνοιξε το [`index.html`](./index.html) στον browser ή σερβίρισέ τον φάκελο τοπικά:

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

Μετά πήγαινε στο `http://127.0.0.1:8000/oikonomika/`.

## Δεδομένα

- Αποθήκευση στο `localStorage` του browser (χωρίς login).
- Εξαγωγή / εισαγωγή JSON για αντίγραφο ασφαλείας.
- Τα δεδομένα μένουν στη συσκευή σου· δεν στέλνονται σε server.
